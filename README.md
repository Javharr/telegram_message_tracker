# Telegram Message Tracker

Telegram-бот на Python и aiogram для сохранения входящих сообщений и медиа через Telegram Chat Automation.

## Возможности

- сохранение входящих сообщений;
- уведомления об удалённых сообщениях;
- уведомления об изменённых сообщениях;
- сохранение фото, видео, голосовых и документов;
- получение одноразовых медиа через ответ;
- статистика;
- удаление пользовательских данных;
- поддержка нескольких пользователей.
